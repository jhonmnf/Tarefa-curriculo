# Currículo em HTML e CSS

Exercício de criação de uma página de currículo com HTML e CSS.

## Abrir o projeto

Clone o repositório e abra `curriculo/Curriculo.html` em um navegador.

## Estrutura

- `curriculo/Curriculo.html`: conteúdo da página.
- `curriculo/Style.css`: folha de estilos.

## Ponto de atenção

O HTML referencia `style.css`, mas o nome versionado é `Style.css`. Essa diferença pode impedir o carregamento dos estilos em hospedagens que distinguem maiúsculas de minúsculas.

## Status

Exercício estático, sem dependências de build ou testes automatizados.
